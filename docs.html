BetterYTS API

Free, keyless and CORS-enabled. Every result comes back with ads, promoted videos and filler shelves already stripped out.

💡 Base URL

All endpoints live on https://yts.foulfoxhacks.dev. Prefer the browser? The search page runs on this same API. Machine-readable: /api/openapi.json (OpenAPI 3.1) to generate clients in any language.

VRChat & media-player redirects

Paste any of these into a video player such as ProTV, USharpVideo or iwaSync. Each one answers with an HTTP 302 to the matching YouTube video, and the player takes it from there.

https://yts.foulfoxhacks.dev/search?q=lofi hip hop
https://yts.foulfoxhacks.dev/search?=lofi hip hop        # same thing
https://yts.foulfoxhacks.dev/search?lofi+hip+hop         # same thing
https://yts.foulfoxhacks.dev/lofi hip hop                # u2b.cx-style shortcut
https://yts.foulfoxhacks.dev/lucky?q=lofi&n=2            # 2nd result, always redirects
https://yts.foulfoxhacks.dev/v/dQw4w9WgXcQ               # by video ID

In a normal browser tab, /search shows the results page instead. Add &lucky to force the redirect. If the query is a YouTube link, you go straight to that video.

⚠️ Untrusted URLs

VRChat only plays URLs from its trusted list unless Allow Untrusted URLs is on in Comfort & Safety settings. That applies to every custom search domain, u2b.cx included.

Search operators

Type these into any search (the site, /api/search, /search and /lucky redirects, so they work from a VRChat URL too). URL options win over operators; the rest of the query goes to YouTube.

OperatorEffect
channel:@handle, channel:"Two Words"Only results from that channel (by @handle, name or ID).
-channel:nameNever results from that channel.
-word, -"a phrase"Drop results whose title or channel contains it.
-shorts, shorts:onlyNo Shorts, or only Shorts.
duration:short|medium|long (or long:true)Under 4 min, 4–20 min, over 20 min.
sort:date|views|rating, upload:hour|today|week|month|year, type:video|channel|playlistSame as the URL options.
is:4k, has:subtitles, hd:trueFeatures: 4k hd hdr cc subtitles live 360 vr180 3d location.
after:2026-01-01, before:2025-12By upload date. YouTube only says "3 weeks ago", so a result is kept if its date could match.

Example: /search?q=lofi channel:@LofiGirl -shorts duration:long. Responses include an operators object and blocked.operators, the number of results the operators removed.

Add-on endpoints

GET/api/segments/{id}

SponsorBlock segments. BetterYTS looks them up through SponsorBlock's hash-prefix API, so SponsorBlock never sees exactly which video you asked about. Filter with ?categories=sponsor,intro.

Categories: sponsor, selfpromo, exclusive_access, interaction, intro, outro, preview, hook, filler, music_offtopic, poi_highlight, chapter.

GET/api/dislikes/{id}

Likes and estimated dislikes from Return YouTube Dislike.

GET/api/branding/{id}

DeArrow's community title and thumbnail, or null. For many videos at once, use /api/branding?ids=a,b,c (up to 30 IDs). It returns an object keyed by ID.

GET/api/suggest

Autocomplete suggestions for ?q=, as a plain JSON array of strings.

GET/api/playlist/{id}

A YouTube playlist's title, owner, counts and videos (100 per page; pass next back as ?page=). Accepts IDs or full playlist URLs.

GET /api/playlist/PLFgquLnL59alCl_2TQvOiD5Vgm1hCaGSI
{ "id": "PL…", "title": "…", "owner": "…", "videoCount": "182 videos", "views": "…", "results": [ … ], "next": "…" }

GET/api/channel/{id}

A channel by ID (UC…) or @handle: title, handle, avatar, banner, subscribers, and one tab of content. tab is videos (default), live, shorts or playlists; paginate with page.

GET /api/channel/@LofiGirl?tab=live

In-world search for VRChat

The /vrc/* endpoints power the BetterYTS In-World Search prefab (VCC listing: https://vpm.foulfoxhacks.dev/index.json). Udon can't build URLs at runtime, so worlds bake a pool of /vrc/p/{slot} URLs and the server hands out slots for each result, a thumbnail sheet, and the next page.

New to BetterYTS? Follow the step-by-step world setup guide (VCC, the search panel, ProTV, troubleshooting). In-world search responses carry "v": 1 (search protocol v1); linking responses carry "v": 2 (linking protocol v2). They're versioned separately.

EndpointReturns
GET /vrc/infoProtocol version, pool size and URL pattern.
GET /vrc/search?q=12 playable videos with pool slots, a sheet slot and a next-page slot (VRCJson-friendly).
GET /vrc/p/{slot}A video (302 to YouTube), the thumbnail sheet (JPEG, served directly), or the next page (JSON).

Full contract: docs/vrchat-protocol.md.

GET/vrc/protv.playlist

A ProTV playlist file built from a YouTube search (?q=) or playlist (?list=), up to n entries (1–500, default 50). In a ProTV Playlist, set Media Entries to Remote URL, paste the link, then click Download and Import.

https://yts.foulfoxhacks.dev/vrc/protv.playlist?q=lofi%20hip%20hop&n=50
https://yts.foulfoxhacks.dev/vrc/protv.playlist?list=PLFgquLnL59alCl_2TQvOiD5Vgm1hCaGSI&n=200

Watch-party rooms

Rooms keep everyone on the same video and timestamp with a shared queue. Create or join one from the site's Library › Watch party, or with the API:

EndpointWhat it does
GET /api/rooms/newReturns a new 6-character room code and a hostKey. Keep the key: sending it in hello makes you the host.
GET /api/rooms/{code}Current video, playback position, queue and member count.
WS /api/rooms/{code}/wsJoin. Send load, play, pause, seek, next, ended, queue_add, queue_remove; receive state and members. Send {"t":"hello","name":…,"key":hostKey} to join as host (you get {"t":"you","host":true}); hosts can send {"t":"lock","locked":true} so only hosts control playback and the queue. Refused messages get {"t":"denied"}. Time sync: send {"t":"ping","c":Date.now()} and get {"t":"pong","c":…,"s":serverMs}; offset ≈ s − (c + rtt/2), best from the fastest round trip. Starts are scheduled: a playing state.at may be a moment in the future, so everyone starts together. Up to 10 messages a second per member.
GET /room/{code}For VRChat players: 302 to what the room is playing right now, at the current time.
GET /auth/google/start
POST /api/auth/google/token|refresh|revoke		Google sign-in broker for the BetterYTS Music app (read-only YouTube library import, PKCE). Tokens pass through and are never stored or logged. Not for use from web pages.

Rooms are deleted after 24 hours without anyone connected. Up to 50 people per room.

Linking accounts in VRChat

Status: the server side is live; the world-side linking UI isn't in a released VRChat package yet. TikTok linking is in testing (only TikTok tester accounts can sign in).

Players can bring their own music into a world: YouTube playlists (Google sign-in), Spotify playlist links, or their BetterYTS library. The world shows a code; the player enters it at yts.foulfoxhacks.dev/inworld/youtube/auth (or /inworld/spotify/auth) and picks playlists; it's for this visit unless they choose to save it (kept up to 30 days under a two-part key the world keeps in PlayerData; Unlink deletes it). Everything uses baked URLs: /vrc/link/start/{youtube|spotify|tiktok}, the pool /vrc/p/{slot}, /vrc/l/{0…9999} + /vrc/k/{0…9999} and /vrc/forget. See the privacy policy. Full protocol: docs/vrchat-protocol.md › Linking.

Community plugins

Plugins on the site and in BetterYTS Music are grouped into categories, each with its own switch: Playback, Player, Look and BetterYTS. Anyone can write a community plugin for Player or Look; Playback and BetterYTS are built-in only, because what they do (control playback, rooms, the network) can't be sandboxed safely. Install one in Settings › Plugins › Add a community plugin, by pasting its manifest.

CategoryPermissions it may ask for
PlayernowPlaying: get { id, title, channel, position, duration, playing } when the video changes and every few seconds. panel: show up to 500 characters of text next to the video (shown as text, never HTML).
Lookpalette: set accent and/or hot to #rrggbb colours. No code.
 
{
  "id": "song-clock",
  "name": "Song clock",
  "version": "1.0.0",
  "author": "you",
  "description": "Shows how long is left.",
  "category": "Player",
  "permissions": ["nowPlaying", "panel"],
  "code": "betteryts.on('nowPlaying', n => { const left = Math.max(0, n.duration - n.position); betteryts.panel(n.title + ': ' + Math.floor(left / 60) + ' min ' + Math.round(left % 60) + ' s left'); });"
}

The sandbox. Code runs in a Web Worker inside /plugin-sandbox, a frame with sandbox="allow-scripts" (an opaque origin: none of the site's cookies, storage or page) and a default-src 'none' policy, so no network at all; in the app, the same page runs in a WebView with network loads blocked. The only API is betteryts.on(type, fn) and betteryts.panel(text), and only for the permissions granted. A plugin that stops responding is stopped. Limits: id 3–32 of a-z 0-9 -, 20 KB of code, 10 plugins.

Errors & caching

Errors use normal HTTP status codes and a JSON body:

{ "error": { "status": 400, "message": "Missing search query. Use /api/search?q=your+search" } }

Responses are cached at Cloudflare's edge for 5–30 minutes. The X-Cache header shows whether a response was a HIT or a MISS.
