VRChat & media-player redirects

Paste any of these into a video player. They answer with an HTTP 302 to the matching YouTube video, which VRChat's player then resolves.

https://yts.foulfoxhacks.dev/search?q=lofi hip hop
https://yts.foulfoxhacks.dev/search?=lofi hip hop        (same thing)
https://yts.foulfoxhacks.dev/search?lofi+hip+hop         (same thing)
https://yts.foulfoxhacks.dev/lofi hip hop                (u2b.cx-style shortcut)
https://yts.foulfoxhacks.dev/lucky?q=lofi&n=2            (2nd result, always redirects)
https://yts.foulfoxhacks.dev/v/dQw4w9WgXcQ               (by video ID)

Opened in a normal browser tab, /search shows the results page instead. Add &lucky to force the redirect anywhere. Pasting a YouTube URL as the query redirects straight to that video.

OptionDefaultWhat it does
n1Play the nth result (1–20).
shorts0Allow Shorts to be picked.
live1Allow live streams to be picked (live=0 skips them).
minlen / maxlen—Only pick videos at least / at most this many seconds long.
sortrelevancerelevance, date, views, rating
duration—short (<4 min), medium (4–20), long (>20)
upload—hour, today, week, month, year
features—Comma list: hd, 4k, live, subtitles, cc, hdr, 360, vr180, 3d
towatchRedirect target: watch (youtube.com), youtu.be, embed (youtube-nocookie), music
hl / glen / USLanguage and region of the search.

VRChat only plays URLs from its trusted list unless Allow Untrusted URLs is on in Comfort & Safety settings. That applies to every custom search domain, including u2b.cx.

GET /api/search

GET /api/search?q=minecraft+music&type=video&sort=views
ParamValues
qSearch text (max 200 chars). ?= and bare ?term also work.
typeall (default), video, channel, playlist, movie
sort, duration, upload, featuresSame as the redirect options above.
shorts1 (default) keeps Shorts mixed into results, 0 removes them.
shelves0 (default) drops "People also watched", Shorts shelves and similar filler; 1 keeps them, tagged with shelf.
dearrow1 attaches DeArrow titles and thumbnails to each video as branding.
pageThe next token from a previous response.
hl, glLanguage and region.

Add-on endpoints

GET /api/segments/{id}?categories=sponsor,intro

SponsorBlock segments. Looked up with SponsorBlock's hash-prefix API, so SponsorBlock never sees exactly which video you asked about. Categories: sponsor, selfpromo, exclusive_access, interaction, intro, outro, preview, hook, filler, music_offtopic, poi_highlight, chapter.

GET /api/dislikes/{id}

Likes and estimated dislikes from Return YouTube Dislike.

GET /api/branding/{id} · GET /api/branding?ids=a,b,c

DeArrow's community title and thumbnail (or null). The batch form takes up to 30 IDs and returns an object keyed by ID.

GET /api/suggest?q=

Autocomplete suggestions as a plain JSON array of strings.
