BetterYTS

Ad-free YouTube search for the web and VRChat, with SponsorBlock, DeArrow and Return YouTube Dislike built in.

/
    Use it in VRChat 🎬 Read the API Docs View on GitHub

    Ad-free by Default

    Ad slots, promoted videos, Shorts shelves and "People also watched" filler are stripped on the server before results ever reach you. Every search tells you what it blocked.

    Community Add-ons Built In

    SponsorBlock skips sponsor reads automatically, DeArrow swaps clickbait for honest titles and thumbnails, and Return YouTube Dislike brings the dislike count back.

    Made for VRChat

    One link plays the top result in any world's video player. Pick the 2nd result, skip Shorts, cap the length, or filter by date — all from the URL. Free and open source, forever.

    Use it in VRChat

    Paste a search link into any world's video player — ProTV, USharpVideo, iwaSync and the rest all work. The link redirects to the top YouTube result, so there are no menus and no ads.

    Video player URL
    /search?q=your search here

    ⚠️ Untrusted URLs

    VRChat only plays custom domains when Allow Untrusted URLs is on (Settings → Comfort & Safety). That applies to every search service, u2b.cx included. Need a link that works with it off? Open a video here and use Copy for VRChat.

    Handy options
